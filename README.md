A make.fun bounty entry: the one line a smart fridge texts its owner at 3am.

> It's 3am. You've opened me 4 times tonight and eaten nothing. I'm not a museum. Go to bed.

The fridge has been awake all night, counting. At 3am it finally speaks — a small machine with an opinion and no shame about sharing it. Running `python3 main.py` writes the line to `/output/entry.txt`.
